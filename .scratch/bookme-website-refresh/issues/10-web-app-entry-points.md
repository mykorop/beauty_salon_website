# 10: Відкрити вебдодаток із навігації та головної BookMe

**What to build:** Відвідувач RO/EN сайту відкриває BookMe у браузері зі спільної навігації, вступу головної або блоку завантажень. Він розуміє різницю між вебдоступом і встановленням клієнтського чи бізнес-застосунку та може скористатися кожним варіантом із телефона, комп'ютера або без JavaScript.

**Blocked by:** 03: Показати клієнтам і бізнесу можливості BookMe та правильні завантаження.

**Status:** resolved

- [x] Помітне посилання на вебдодаток є у спільній навігації всіх восьми сторінок, у вступі обох головних та на спільному рівні блоку завантажень. На mobile воно залишається видимим і доступним.
- [x] Усі ці посилання мають точний href https://app.bookme.md/, відкриваються в поточній вкладці та працюють без JavaScript. Адреса походить з одного спільного визначення; не додаються непідтверджені deep links, мовні параметри або автоматичні перенаправлення.
- [x] Підпис RO — «Deschide aplicația web», EN — «Open web app»; пояснення у блоці завантажень повідомляє про можливість користування в браузері. Тексти не обіцяють обхід onboarding/авторизації та не називають адресу окремим входом до BookMe Business.
- [x] Зберігаються два напрями для клієнтів і бізнесу та зв'язок назв BookMe Business / BookMe Salon. Клієнтські магазинні URL залишаються https://play.google.com/store/apps/details?id=md.bookme.client і https://apps.apple.com/us/app/bookme/id6779576243; бізнесові — https://play.google.com/store/apps/details?id=md.bookme.business і https://apps.apple.com/ua/app/bookme-salon/id6779576340?l=uk.
- [x] Посилання вписані в графітово-золотистий дизайн; локалізований текст не перекриває меню, мовний перемикач чи основні кнопки. Перевірені 320/768/1440 CSS px без горизонтального переповнення.
- [x] Клавіатура досягає кожного нового посилання; фокус видимий і не перекритий, доступні назви зрозумілі, інтерактивні цілі щонайменше 44×44 CSS px.
- [x] Наявні Playwright-перевірки готової production-збірки доповнені точними href і розміщенням у RO/EN: навігація на всіх восьми сторінках, вступ і завантаження на двох головних. Перехід мишею та клавіатурою перевіряється з перехопленням зовнішньої навігації, без залежності від production BookMe.
- [x] Браузерний проєкт без JavaScript перевіряє нові посилання; чинні перевірки мовних переходів, двох аудиторій і чотирьох магазинних URL проходять. Axe не виявляє порушень у змінених областях.
- [x] Перевірка Astro/типів, статична збірка й доречні браузерні тести проходять; основний контент залишається у початковому HTML. Власний JavaScript не перевищує 20 КБ gzip, CSS — 40 КБ gzip на сторінку.

## Answer

Додано звичайні HTML-посилання на вебдодаток у спільній навігації всіх восьми сторінок, у вступі обох головних і над двома картками завантажень. Усі використовують `webAppUrl` із `src/content/apps.ts`, мають точний href `https://app.bookme.md/` та відкриваються в поточній вкладці без JavaScript. Підписи централізовано в `src/i18n.ts`.

Спільний блок над завантаженнями пояснює користування BookMe у браузері на телефоні або комп'ютері та відокремлює його від встановлення застосунків. Обидва напрями, чотири магазинні URL та пояснення BookMe Business / BookMe Salon збережено. Золотисте посилання в навігації залишається видимим на mobile; меню переходить на окремий рядок до того, як довгий RO-підпис почне тіснити мовний перемикач.
