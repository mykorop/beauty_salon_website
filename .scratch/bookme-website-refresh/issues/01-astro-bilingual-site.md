# 01: Перенести всі сторінки на Astro та запровадити RO/EN

**What to build:** Відвідувач відкриває чотири наявні сторінки румунською або англійською, перемикає мову й користується навігацією в єдиному темному оформленні. Сайт збирається у статичний артефакт. Це початкова міграція, яка створює робочу основу для наступних змін контенту.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Astro генерує вісім повних HTML-сторінок: головну, конфіденційність, умови та видалення акаунта для RO і EN. Румунська — основна, англійська використовує префікс /en/.
- [x] Чинні публічні .html-адреси юридичних сторінок та index.html продовжують відкриватися напряму; build.format preserve зберігає необхідну форму вихідних URL.
- [x] Навігація, підвал, юридичний макет і мовний перемикач спільні. Перемикач відкриває відповідну мовну версію сторінки; автоматичних мовних перенаправлень немає.
- [x] Запроваджено графітову палітру із золотистим акцентом, локальні DM Sans та Instrument Serif із румунськими діакритичними знаками. Основний текст і фокус відповідають контрастності WCAG 2.2 AA.
- [x] Поточний контент перенесено й локалізовано без нових юридичних обіцянок. Остаточне переписування головної та юридичних документів належить наступним задачам.
- [x] Основний контент і навігація працюють без JavaScript; меню доступне клавіатурою, має видимий фокус і коректні доступні назви.
- [x] Існуюча контактна форма зберігає контракт FormBold. Міграція не змінює мобільні застосунки, API чи бекенд.
- [x] Залежності та сумісну версію Node зафіксовано; задокументовані локальний запуск, статична збірка й перевірки.
- [x] Playwright перевіряє готову production-збірку: вісім сторінок, прямі старі URL, мовні переходи та навігацію без JavaScript. CI запускає перевірку типів, збірку та ці smoke-тести.


## Answer

Реалізовано міграцію на Astro: вісім статичних сторінок RO/EN, збережені прямі `.html`-адреси, спільні компоненти навігації, підвалу, юридичного макета та мовного перемикача. Додано графітову палітру із золотистим акцентом, локальні шрифти з Latin Extended та їхні ліцензії. Юридичні тексти англійською й початкові дати оновлення збережено; румунські версії перекладено без нових обіцянок. Контракт FormBold збережено для звичайного POST та JavaScript-відправлення.

Node 24.20.0 і залежності зафіксовано. Команди запуску, збірки, перевірок і вимоги до статичного хостингу описано в [README](../../../README.md). CI запускає перевірку типів, збірку та Playwright.

Перевірено 17 вересня 2026 року:

- `npm run check`: 0 помилок, попереджень і підказок.
- `npm run build`: рівно 8 HTML-файлів.
- `npm test`: 40 успішних перевірок; 2 перевірки JavaScript-повторної спроби пропущено лише в проєкті без JavaScript. Звичайний POST перевірено для обох мов.
- Зіставлення з початковими HTML-файлами підтвердило збереження всього англійського юридичного тексту.
- Перевірено вигляд головної сторінки на desktop/mobile та юридичної сторінки на mobile, відсутність горизонтального переповнення при 320 px, навігацію клавіатурою і локальне завантаження шрифтів.
- Мінімальний контраст на основних поверхнях: основний текст 13,23:1, другорядний текст 7,58:1, золотистий акцент і фокус 8,36:1; межі полів 4,22:1.
- Тести FormBold перехоплюють зовнішній запит; справжні повідомлення не надсилалися.
