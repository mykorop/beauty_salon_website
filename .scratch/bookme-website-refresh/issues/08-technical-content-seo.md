# 08: Забезпечити коректну індексацію всіх мовних сторінок

**What to build:** Пошукові системи отримують повний HTML, правильну основну адресу й мовні альтернативи кожної сторінки. Відвідувачі бачать доречні назви й описи BookMe без дублювання сторінок у пошуку.

**Blocked by:** 01: Перенести всі сторінки на Astro та запровадити RO/EN.

**Status:** resolved

- [x] На всіх восьми сторінках є унікальні локалізовані title/description, один змістовний H1, коректний lang, абсолютний self-canonical та взаємні hreflang ro/en/x-default.
- [x] Канонічний домен — https://bookme.md; головні canonical — / та /en/. Прямі index.html мають той самий canonical, що й відповідна головна; x-default посилається на румунський відповідник.
- [x] Мовні посилання, canonical і sitemap походять з однієї узгодженої карти публічних сторінок; внутрішні посилання використовують канонічні адреси.
- [x] Sitemap містить лише вісім канонічних індексованих сторінок із мовними альтернативами. Robots.txt посилається на sitemap і не блокує потрібний контент або favicon.
- [x] Оформлена 404-сторінка має зрозумілий шлях повернення, виключена із sitemap та не індексується; тестовий статичний сервер повертає HTTP 404 для невідомого URL, без SPA-fallback на головну.
- [x] JSON-LD описує Organization, WebSite, WebPage і два SoftwareApplication з підтвердженими властивостями. Немає вигаданих aggregateRating/review або обіцянок розширених результатів.
- [x] Тексти природно відповідають пошуку запису до салонів/майстрів у Молдові та потребам бізнесу; дотримано логічну ієрархію заголовків, змістовні посилання й alt-тексти.
- [x] Контроль production-збірки виявляє відсутні метадані, дублікати, випадковий noindex на основних сторінках, неправильні canonical/hreflang, невалідний JSON-LD і зламані внутрішні посилання.
- [x] Задокументовані майбутні перевірки production: індексованість, домен/HTTPS, статуси, sitemap, Search Console та PageSpeed Insights. Публікація, DNS і підключення зовнішніх акаунтів не виконуються.

## Answer

Додано спільну карту восьми канонічних RO/EN-сторінок у `src/i18n.ts`, self-canonical та взаємні мовні альтернативи, статичні `sitemap.xml` і `robots.txt`. Прямі `index.html` збережено з canonical на `/` та `/en/`. Наявні локалізовані метадані, тексти про Молдову, заголовки й доступні описи ілюстрацій перевірено без зайвого переписування.

Оформлена двомовна `404.html` містить `noindex, follow` та посилання повернення RO/EN; невідомі адреси у production preview повертають HTTP 404. JSON-LD містить Organization, WebSite і поточну WebPage; головні додатково описують два SoftwareApplication. Назви, описи й магазини застосунків спільні з видимим блоком завантаження. Джерела підтверджених властивостей і майбутні production-перевірки наведено в [SEO guide](../../../docs/seo.md).

Перевірено 18 вересня 2026 року:

- `npm run check`: 0 помилок, попереджень і підказок.
- `npm run build`: 8 індексованих сторінок + `404.html`, sitemap і robots.
- `npm test -- tests/seo.spec.ts`: 12 успішних перевірок на desktop та mobile без JavaScript.
- `npm test`: 194 успішних перевірки; 12 штатних пропусків перевірок, що потребують JavaScript.
- Тимчасові зміни готового HTML підтвердили виявлення 10 типів регресій: відсутній description, дублікати title/description, noindex, неправильні canonical/hreflang, синтаксично пошкоджений JSON-LD, неправильний тип його вузла, зламаний внутрішній URL і fragment. Після кожного експерименту оригінальний файл відновлено; фінальну збірку виконано заново.
- Візуально перевірено 404 при 320 і 1440 px; автоматично перевірено відсутність переповнення при 320/768/1440 px та axe на desktop.

Додано `npm run test:seo` для перебудови й окремого запуску SEO-контролю. Публікація сайту, DNS та підключення зовнішніх акаунтів не виконувалися; production-перевірки залишаються майбутньою роботою після окремо дозволеної публікації.
