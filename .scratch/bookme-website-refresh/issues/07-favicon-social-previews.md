# 07: Створити впізнавані favicon і прев’ю посилань BookMe

**What to build:** BookMe впізнається у вкладках браузера, закладках, на домашньому екрані й у прев’ю посилань. Усі мовні сторінки використовують узгоджену графіку та локалізовані описи.

**Blocked by:** 01: Перенести всі сторінки на Astro та запровадити RO/EN.

**Status:** resolved

- [x] Через imagegen створено новий майстер-знак на основі існуючої B у геомітці: золотистий символ, графітове тло, проста геометрія, товсті контури та відсутність дрібного тексту.
- [x] Знак перевірено у фактичних розмірах 16/32/48 px на світлих і темних вкладках; його можна розпізнати без збільшеного прев'ю.
- [x] Підготовлено ICO 16/32/48, PNG 96, Apple Touch Icon 180 та іконки 192/512 для web manifest. Растрові результати мають правильні розміри й типи вмісту.
- [x] Створені брендовані Open Graph прев'ю 1200×630 для RO та EN; текст читається в типовому прев'ю й не містить непідтвердженої статистики.
- [x] Усі вісім сторінок містять коректні посилання на favicon, touch icon і manifest, а також локалізовані Open Graph/Twitter Card метадані з абсолютними адресами зображень.
- [x] Майстер, фінальний промпт і результати збережені в проєкті. URL favicon стабільний; для його завантаження не потрібні зовнішні сервіси генерації.
- [x] Не додаються service worker, offline-режим або рекламні інтеграції. Іконки доступні без JavaScript та не блокуються від індексації.
- [x] Перевірки production-збірки підтверджують доступність і розміри ресурсів, валідний manifest, правильні локалізовані метадані та відсутність дубльованих favicon/OG-тегів.

## Answer

Створено новий золотистий знак B у геомітці через вбудований imagegen на основі чинної іконки клієнтського застосунку. Майстер, референс, точні промпти та знімки перевірок збережені в [design/branding](../../../design/branding/README.md). Експорт усіх розмірів і RO/EN-карток відтворюється локально командою `node scripts/generate-branding.mjs`, без повторної генерації через зовнішні сервіси.

У `public/` додано ICO з кадрами 16/32/48, PNG 96, Apple Touch Icon 180, manifest та іконки 192/512, дві PNG-картки 1200×630. Спільний SiteLayout формує однакові посилання на іконки й локалізовані Open Graph/Twitter-метадані на всіх восьми сторінках. Юридичні сторінки отримали власні короткі описи. Абсолютні соціальні URL використовують `https://bookme.md`, визначений у конфігурації Astro. Manifest відкриває інформаційний сайт у браузері; service worker, offline-функції й реклама не додані.

Перевірено 17 вересня 2026 року:

- TDD на визначеній задачею межі production HTML/HTTP: спочатку зафіксовано відсутні favicon, manifest і теги, потім перевірки пройшли після реалізації.
- `npm run check`: 0 помилок, попереджень і підказок.
- `npm run build`: 8 HTML-сторінок і всі статичні ресурси.
- `npm test -- tests/branding.spec.ts`: 20 успішних перевірок на desktop та mobile без JavaScript.
- `npm test`: 182 успішні перевірки, 12 очікуваних пропусків JavaScript-сценаріїв/axe у проєкті без JavaScript.
- HTTP-статуси, MIME, сигнатури та розміри PNG, три кадри ICO, JSON manifest, локалізація, абсолютні URL й відсутність повторних тегів перевірені на production preview.
- [Знак у фактичних розмірах](../../../design/branding/favicon-size-check.png) переглянуто при масштабі 1× на світлому й темному тлі вкладок; [картки](../../../design/branding/social-size-check.png) — при 600×315. Заголовки й румунські діакритичні знаки читаються.
- Перевірено відсутність правил robots, що блокують ці ресурси. Перевірки стосуються локальної production-збірки; кеші зовнішніх соціальних платформ не перевірялися.
